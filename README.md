# Knowledge Representation and Advanced Search (KRAS)

This repository contains my coursework, assignments, and projects for the **Knowledge Representation and Advanced Search** course.

## 📖 Course Overview
The course covers advanced concepts in Artificial Intelligence, focusing on how knowledge can be represented symbolically and manipulated computationally, as well as advanced search algorithms for problem-solving.

### Key Topics:
*   **Advanced Search:** Heuristic search, A* Algorithm, Local Search (Simulated Annealing, Genetic Algorithms), Adversarial Search (Minimax, Alpha-Beta pruning).
*   **Knowledge Representation:** Propositional Logic, First-Order Logic (FOL), Resolution, Ontologies, Semantic Networks, and Knowledge Graphs.

## 📂 Repository Structure
*   `docs/`: Lecture notes and reference materials.
*   `assignments/`: Source code and reports for weekly homework/labs.
*   `projects/`: Final project implementation applying KRAS algorithms.
